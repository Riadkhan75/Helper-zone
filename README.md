# 🎓 Campus Help Zone (ক্যাম্পাস হেল্প জোন)
### আধুনিক, নিরাপদ ও পূর্ণাঙ্গ কলেজ স্টুডেন্ট কমিউনিটি প্ল্যাটফর্ম

Campus Help Zone হলো কলেজ ও বিশ্ববিদ্যালয় শিক্ষার্থীদের জন্য একটি সর্বাধুনিক ওয়েব ও মোবাইল প্ল্যাটফর্ম। এর মাধ্যমে শিক্ষার্থীরা হ্যান্ডনোট ও প্রশ্নব্যাংক ডাউনলোড করতে পারে, পুরোনো একাডেমিক বই কেনাবেচা বা বিনিময় করতে পারে, ক্যাম্পাসে হারানো যেকোনো জিনিস নিরাপদে ফেরত পেতে পারে এবং কমিউনিটিতে পড়াশোনা ও ক্যারিয়ার সংক্রান্ত সাহায্য নিতে পারে।

## 📲 হোমপেজে অ্যাপের মতো ডাউনলোড ও ইনস্টল (PWA)

Campus Help Zone এখন একটি পূর্ণাঙ্গ **Progressive Web App (PWA)**:
1. **হোমপেজ ব্যানার:** হোমপেজে "ক্যাম্পাস হেল্প জোন অ্যাপ ফোনে ডাউনলোড করুন" শিরোনামে একটি আকর্ষণীয় কার্ড রয়েছে।
2. **১ ক্লিকে ইনস্টল:** **"অ্যাপ ডাউনলোড ও ইনস্টল"** বাটনে চাপ দিলে ব্রাউজার স্বয়ংক্রিয়ভাবে ফোনে অ্যাপ ইনস্টল করতে বলবে।
3. **আইফোন (iOS) ও অ্যান্ড্রয়েড গাইড:** ব্রাউজার অটো-প্রম্পট সাপোর্ট না করলেও "কীভাবে ইনস্টল করবেন?" বাটনে ক্লিক করলে সহজ ৩ ধাপের ভিজ্যুয়াল নির্দেশনা দেখানো হয়:
   - **Android Chrome:** ৩ ডট মেনু (⋮) > `Install app` বা `Add to Home screen`।
   - **iPhone Safari:** শেয়ার বাটন (Share) > `Add to Home Screen`।
4. ইনস্টল হয়ে গেলে এটি ফোনের অ্যাপ ড্রয়ার ও হোম স্ক্রিনে চলে আসে এবং ফুল-স্ক্রিন মোডে অ্যাপের মতো কাজ করে।

## 🛡️ এডমিন প্যানেল ফিচার (`/adminriad`)

এডমিন রুটে (`/adminriad`) এখন সকল বিভাগ সক্রিয় রয়েছে:

### ১. বইয়ের লিস্টিং ব্যবস্থাপনা (`বইয়ের লিস্টিং` ট্যাব)
- মোট বইয়ের সংখ্যা ও স্ট্যাটাস ফিল্টার (উপলব্ধ / সংরক্ষিত / বিক্রি শেষ)।
- বইয়ের নাম, লেখক বা বিক্রেতার নাম দিয়ে সার্চ।
- বিক্রেতার ফোন নম্বর পর্যবেক্ষণ ও নিরাপত্তা যাচাই।
- স্ট্যাটাস সরাসরি ড্রপডাউন থেকে পরিবর্তন (Available, Reserved, Sold)।
- ভুয়া বা অপ্রাসঙ্গিক বইয়ের বিজ্ঞাপন এক ক্লিকে স্থায়ীভাবে ডিলিট।

### ২. লস্ট অ্যান্ড ফাউন্ড ব্যবস্থাপনা (`লস্ট অ্যান্ড ফাউন্ড` ট্যাব)
- মোট বিজ্ঞপ্তি ও ফিল্টার (হারানো / পাওয়া গেছে / ফেরত প্রাপ্ত)।
- আইডি কার্ড বা সংবেদনশীল নথির জন্য গোপনীয়তা সতর্কতা পর্যবেক্ষণ।
- আইটেমের স্থান, তারিখ এবং পোস্টদাতার যোগাযোগ নম্বর যাচাই।
- জিনিসটি মালিক খুঁজে পেলে সরাসরি **"ফেরত মার্ক করুন"** বাটন।
- অনুপযুক্ত বিজ্ঞপ্তি মুছে ফেলার সুবিধা।

### ৩. রিপোর্ট ও অভিযোগ কিউ (`রিপোর্ট কিউ` ট্যাব)
- শিক্ষার্থীদের রিপোর্টকৃত পোস্ট, ফাইল ও ভুয়া বিজ্ঞপ্তির তালিকা।
- ফিল্টার: অপেক্ষমাণ (Pending), নিষ্পত্তিকৃত (Resolved), খারিজকৃত (Dismissed)।
- অভিযোগের কারণ (স্প্যাম, ভুয়া তথ্য, অশালীন বক্তব্য ইত্যাদি) ও বিস্তারিত বিবরণ।
- **"পদক্ষেপ সম্পন্ন"** বা **"খারিজ করুন"** বাটনে ক্লিকে তাৎক্ষণিক সমাধান।

## 🌐 ক্রস-ডিভাইস লাইভ সিঙ্ক গাইড

### সমস্যাটি কেন হতো?
পূর্বে যখন একটি নতুন মোবাইল বা ব্রাউজার সাইটে প্রবেশ করত, তার মেমোরি খালি থাকার কারণে সে ডিফল্ট ফাঁকা ডেটা সার্ভারে পাঠিয়ে দিত। ফলে অন্য মোবাইলের করা নতুন পোস্ট মুছে যেত।

### সমাধান:
১. **সেফ ইনিশিয়ালাইজেশন:** নতুন মোবাইল সাইটে প্রবেশ করলে সে কখনোই সার্ভারের ডেটা ওভাররাইট করে না; বরং প্রথমে সার্ভার থেকে লেটেস্ট ডেটা গ্রহণ করে।
২. **৩ সেকেন্ড অটো-পোলিং:** প্রতি ৩ সেকেন্ড পর পর এবং উইন্ডোতে ফোকাস এলে স্বয়ংক্রিয়ভাবে সার্ভারের সাথে লাইভ স্টেট সিঙ্ক হয়।
৩. ফলে মোবাইল A থেকে একটি বই বা পোস্ট দিলে, মোবাইল B কোনো রিফ্রেশ ছাড়াই কয়েক সেকেন্ডের মধ্যে তা দেখতে পায়।

## ☁️ Vercel বনাম Google AI Studio

### কেন Vercel-এ আপডেট করলে Google AI Studio-তে পরিবর্তন হয় না?
Google AI Studio এবং Vercel সম্পূর্ণ ভিন্ন দুটি ক্লাউড হোস্টিং সার্ভিস:
- **Google AI Studio:** এটি Google Cloud Run কন্টেইনারে চলে।
- **Vercel:** এটি Vercel-এর নিজস্ব গ্লোবাল সার্ভারলেস নেটওয়ার্কে চলে।
উভয়ের সার্ভার মেমোরি ও ফাইল সিস্টেম আলাদা।

### কীভাবে উভয় জায়গায় এবং সব মোবাইলে একই ডেটা লাইভ দেখবেন?
একটি **কেন্দ্রীয় Firebase Firestore** ডেটাবেস যুক্ত করে দিলেই সমাধান!
Firebase হলো ক্লাউড ডেটাবেস। আপনি যখন একই Firebase API Keys:
1. Google AI Studio-এর `.env` ফাইলে দিবেন, এবং
2. Vercel-এর `Project Settings > Environment Variables`-এ দিবেন,
তখন Vercel ও AI Studio এবং দুনিয়ার যেকোনো মোবাইল সরাসরি একই ক্লাউড ডেটাবেস শেয়ার করবে। কোনো এক জায়গায় পোস্ট করলে সব জায়গায় সাথে সাথে চলে আসবে!

## 🔥 Firebase ক্লাউড ডেটাবেস সেটআপ

1. [Firebase Console](https://console.firebase.google.com/)-এ যান এবং `Add project` ক্লিক করে নতুন প্রজেক্ট তৈরি করুন।
2. **Authentication চালু করুন:**
   - **Build > Authentication**-এ যান।
   - `Email/Password` প্রভাইডার Enable করুন।
3. **Cloud Firestore ডাটাবেস তৈরি করুন:**
   - **Build > Firestore Database**-এ গিয়ে `Create Database` চাপুন (Production mode)।
4. **Web App তৈরি ও API Keys সংগ্রহ:**
   - প্রজেক্ট সেটিংসে গিয়ে Web Icon (</>) ক্লিক করে অ্যাপ রেজিস্টার করুন।
   - `firebaseConfig` এর মানগুলো কপি করুন।

## 🔑 এনভায়রনমেন্ট ভেরিয়েবল (.env কনফিগারেশন)

প্রজেক্টের মূল ফোল্ডারে `.env` ফাইলে কীগুলো বসান (এবং Vercel-এর Environment Variables-এও একই কীগুলো দিন):

```env
# Firebase Client Configuration
VITE_FIREBASE_API_KEY="AIzaSyYourActualApiKeyHere"
VITE_FIREBASE_AUTH_DOMAIN="your-project-id.firebaseapp.com"
VITE_FIREBASE_PROJECT_ID="your-project-id"
VITE_FIREBASE_STORAGE_BUCKET="your-project-id.appspot.com"
VITE_FIREBASE_MESSAGING_SENDER_ID="123456789012"
VITE_FIREBASE_APP_ID="1:123456789012:web:abcdef1234567890"

# প্রধান এডমিন ইমেইল
VITE_ADMIN_EMAIL="nazrulpost75@gmail.com"
```

## 🚀 Vercel Deployment পূর্ণাঙ্গ নির্দেশিকা

1. আপনার রিপোজিটরিটি GitHub-এ Push করুন।
2. [Vercel](https://vercel.com/)-এ গিয়ে **"Add New Project"** সিলেক্ট করে গিটহাব রিপো ইমপোর্ট করুন।
3. **Build settings:**
   - Framework Preset: `Vite`
   - Build Command: `npm run build`
   - Output Directory: `dist`
4. **Environment Variables:**
   - Vercel ড্যাশবোর্ডে গিয়ে `VITE_FIREBASE_API_KEY`, `VITE_FIREBASE_PROJECT_ID` ইত্যাদি যুক্ত করুন।
5. **Deploy** বাটনে চাপুন। অ্যাপটি সফলভাবে লাইভ হয়ে যাবে!
